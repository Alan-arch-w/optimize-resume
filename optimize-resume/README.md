# 简历优化 Skill

边聊边做 · 按岗定制 · 面试准备 · 自选模板

适用于实习、校招、社招和转行求职的简历优化与面试准备 Skill。

你可以上传已有简历，也可以从聊天开始，逐步整理经历。它会根据目标岗位或 JD 优化简历内容与排版，并在简历完成后生成配套面试准备材料。

## 能帮你做什么

### 简单输入，边聊边做

支持文字、口述转写、Word、PDF、截图、旧简历和作品集等材料。信息不完整也可以开始，AI 会先读材料，再分轮询问需要补充的内容。

### 根据 JD 定制

把岗位 JD 一起发给 AI，它会结合你的真实经历，选择相关内容、调整重点与顺序。同一份经历投不同岗位，可以分别生成对应版本。

没有 JD 也可以使用，先告诉 AI 想投什么岗位即可。

### 按 STAR 梳理经历

帮助你讲清项目背景、本人职责、具体行动和实际产出。没有量化数据时，可以通过已完成的交付物和工作范围说明贡献。

### 支持自定义模板

内置简历参考版式，也支持你提供喜欢的参考图片、Word 或 PDF。可以先生成默认版，再沿用已确认的内容调整排版。

### 简历完成后，继续准备面试

结合最终简历和 JD，生成自我介绍、项目讲述逐字稿及分模块问答。除了主问题，也会提供针对性的追问与回答示范。

## 怎么安装

需要在支持自定义 Skill、文件读取和相应文档处理能力的 AI Agent 中使用。各工具的安装入口与文件输出能力不同，请按所用工具的方式安装。

### 方式一 · 把仓库链接发给 Agent

复制下方指令，将占位内容替换为本仓库地址。

```text
请从【本仓库的 GitHub 链接】下载并安装简历优化 Skill（optimize-resume）。请保留 Skill 目录中的参考文件、脚本和模板，安装完成后告诉我如何使用。
```

### 方式二 · 下载后安装

下载本仓库，找到包含 `SKILL.md` 的技能目录，保留其中的 `references`、`scripts` 和 `assets` 等配套文件，再按所用 Agent 的说明导入或安装。

## 怎么使用

### 已有简历草稿

上传草稿，有 JD 时一起上传，然后发送以下指令。

```text
使用简历优化 Skill，帮我优化这份简历。

我想投递【目标岗位】，岗位 JD 是【粘贴 JD，没有可不填】。
缺少的信息请向我提问。完成后输出 Word、PDF 简历和配套面试准备材料。
```

### 还没有简历

```text
使用简历优化 Skill，帮我从零制作简历。

我想投递【目标岗位】，请通过聊天逐步了解我的背景和经历。
完成后输出 Word、PDF 简历和配套面试准备材料。
```

### 想使用自己的模板

上传参考图片或文档，再发送以下指令。

```text
请参考我上传的模板调整简历版式，保留已经确认的简历内容，输出新版 Word 和 PDF。
```

### 想逐题练习面试

```text
请根据最终简历、岗位 JD 和面试准备材料，带我逐题模拟面试。
一次问一题，等我回答后给出具体反馈和回答示范，再进入下一题。
```

## 最后会得到什么

| 交付内容 | 说明 |
| --- | --- |
| Word 简历 | 可继续编辑，支持后续修改内容和版式 |
| PDF 简历 | 完成排版检查后用于投递 |
| 优化说明 | 简要说明调整重点和仍需补充的信息 |
| 面试准备材料 | 默认单独输出 Markdown，按需可要求 Word 或 PDF |

文件生成需要所用 Agent 具备相应能力。环境无法导出附件时，提供可复制的完整文本。

## 面试准备包含哪些内容

| 模块 | 主要内容 |
| --- | --- |
| 自我介绍 | 1 分钟和 3 分钟两个版本的口语逐字稿 |
| 项目与实习讲述 | 各独立项目的长短讲述稿及要点卡 |
| 简历深挖 | 个人贡献、方法、成果与复盘的具体问答 |
| 岗位专业能力 | 根据 JD 核心职责准备专业问题与回答 |
| 业务案例与情境 | 贴近岗位工作的案例分析和解题示范 |
| 行为与协作 | 协作分歧、困难处理、学习与责任承担 |
| 求职动机与匹配 | 岗位选择、转行原因、优势与职业规划 |
| 压力递进问答 | 围绕实际经历进行多轮质疑，每轮配有回应 |
| HR 与实际安排 | 到岗时间、地点、实习时长及其他实际条件 |
| 反向提问与收尾 | 可向面试官提出的问题和后续接话建议 |

材料会按岗位、经历和面试阶段调整，并标出优先练习的内容。逐字稿用于帮助你组织表达，练习时请用自己的话讲清楚。

## 使用前的小提醒

- 请提供真实经历。Skill 会追问缺失信息，保留个人贡献与团队成果的区别。
- 对尚未确认的经历细节，面试材料会给出待补充的回答框架。
- 投递前请核对姓名、联系方式、日期、数字和排版。
- 上传前可遮挡手机号、证件号、详细住址，以及涉及公司保密的信息。
