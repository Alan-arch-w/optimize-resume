# 参考版式与模板优先级

## 先锁定版式

用户明确说“按这份模板”“参考这个版式”时，将该文件视为版式来源。先解析段落、样式、页边距和对齐，再渲染看图；不能仅根据提取文字判断。内容事实仍从事实底稿取，不复制模板中的身份、学历、岗位、数字、夸张评价。用户未指定版式时，使用 `assets/reference-layout.docx`。

## 自适应版式与视觉层级

保留A4单栏、居中姓名/联系方式、黑字白底、蓝色细分隔线、机构左对齐与日期右对齐的视觉语言。把内置DOCX作为样式基底，不固定复制全部字号与段距。

| 层级 | 紧凑 → 舒展参数 | 排版关系 |
| --- | --- | --- |
| 页面 | 上13.4毫米，左右及下约12.5毫米 | 不靠大幅改页边距填满版面 |
| 姓名 | 17–20磅，加粗，居中 | 与联系方式保持约3磅间距 |
| 联系及求职信息 | 与正文同级，居中 | 字数过多时在信息组边界分行，不拆电话、邮箱或日期 |
| 一级章节 | 11–12磅，加粗，蓝色下边框 | 段前8–12磅，段后4–6磅；章间为最大间距 |
| 机构或项目标题 | 9.5–11磅，加粗；日期常规字重 | 同章第二条起段前4–7磅、段后2–3磅；首条不重复叠加段前 |
| 岗位、学位、项目性质 | 9–10.5磅，常规字重，独立行 | 紧接标题，段后2–4磅；与首条分点保持一组 |
| 正文与段内分点 | 9–10.5磅，固定行距12–15磅 | 段后2–3.5磅；短标签加粗、说明常规字重 |

章节之间的视觉距离 > 同章经历之间的距离 > 同一经历内分点之间的距离。不要将每行都设成同样的段前段后，也不要用空段落补间距。正文通常9.5–10.5磅；仅内容较密时使用9磅下限。延续指定模板的分点风格，不强制添加项目符号；有加粗标签时一般不再叠加圆点。每个分点独立成段，自动换行，禁止为视觉对齐硬插换行。过长分点优先精简或拆成两个不同能力点，不拆碎语义。

最终DOCX优先声明收件端常见字体，默认中文微软雅黑、英文Arial。服务器没有这些字体时，配置本机字体替代或使用临时渲染副本，避免将服务器专有字体名写入交付文件。保留层级与字重，验证渲染字体的常规与粗体均覆盖实际用字；不能只因字体名称存在就直接采用。

## 内容量与留白调整

1. 默认 `--density auto` 根据中英文宽度、字号、段落层级与版心高度估算首轮密度。需要明确选择时用 `compact`、`balanced`、`airy`；PDF复查后可用 `--scale 0..1` 微调。它们只能调格式，不能增删候选人事实。
2. 首轮渲染后运行 `inspect_layout.py`。内容充足的一页简历，正文末端一般占到可用版心高度的85%–96%，页底空白约15–30毫米较自然。约35毫米以上空白是复查提示，不是强制失败。联系信息和章节分隔留白计入整体观察，不能把覆盖率误当成墨迹面积。
3. 下方过空时先增大正文可读性，再调整章间、条目间、分点间距。维持上述大小关系，不把所有段距同比放大，也不靠拉大字距、撑大页眉或加空行填满。
4. 内容少到舒展档仍不满时，接受合理留白；不编造经历、不复述自评、不放大到海报字号。可以询问真实补充材料，但不阻塞现有成稿。
5. 内容过多时先精简重复、降低非核心经历篇幅，再按层级收紧；仍超页则合理分页。两页简历需检查页间分配，不留下只有一两行的尾页，不为铺满第二页拉大整篇间距。
6. 章节标题与首条、机构标题与岗位/首分点保持同页；普通短分点尽量不跨页。保留自然分页，不把整章锁成不可分页的大块。

## 外部模板的处理

### 交付后收到参考图片或文档

- 接受完整简历截图、局部排版参考图、DOCX及PDF。先目视查看图片；文档先渲染再查看，不只提取文字。参考图片用于理解版式，不直接作为整页背景代替可编辑简历。
- 提取页面结构、信息位置、字体层级、对齐、分隔线、颜色、分点与间距。用户明确指定整体版式时直接执行；仅提供局部参考时调整对应部分，多张参考存在冲突时只问影响选择的关键点。
- 沿用已有事实底稿与已确认文案。参考中的姓名、学校、经历、数据不属于用户资料；不因换模板改写事实，也不重复追问已经确认的信息。
- 把新参考作为当前版式依据。保留其设计特点，再按真实内容量安排留白与分页；不强行套用内置蓝线或原有模块位置。复杂版式按需重建，保留正文可编辑与可检索性，不能默默退回默认模板。
- 参考图看不清时，先处理可辨认的结构，确有必要再请用户补充清晰图或原文档。完成后将新版与参考并排检查，重新渲染及核对字体兼容，交付更新文件。

`render_resume.py --template reference.docx` 可继承段落样式、页面参数及标题/联系/正文/经历首行格式。外部模板默认保持原字号和间距；仅当用户允许优化版式时使用 `--adapt-template` 开启自适应节奏，并继续保留模板的结构与视觉语言。脚本只复制格式到新文档，不复制源正文、页眉页脚、批注、图片或附件。它不是任意复杂模板的无损复刻器：双栏、表格、文字框、特殊背景或非标准样式需要另外处理，不能默默降级。

本次参考文件使用浮动绘图线作分隔；内置模板以段落下边框实现相同视觉，避免线条漂移。外部模板中同类章节线也转换为稳定的段落线。日期必须完整留在一行；标题过长时把岗位移到次行，或使用统一简短日期，不能将“月”挤到下行。不得复制原文件的错误学历、非真实岗位及无依据商业成果。

## 交付前比对

逐页查看指定模板与成稿渲染图，分别核对姓名/联系方式居中、章节蓝线、标题层级、机构与日期两端对齐、岗位独立成行、短标签加粗、段落密度与页边距。正文需可复制检索。内置版式允许在参数范围内调整字号与垂直节奏；明确要求严格复刻的外部模板保留其参数。新增内容可以改变页数，但不能改变整套视觉样式；内容多时优先保留有效信息，允许第二页，避免孤立标题和一两行尾页。
